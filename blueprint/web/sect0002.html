Definition 28

def:net,def:preset_t immediate_conflict Two different transtions \(t,t'\) are in immediate conflict if \(•t ∩ •t ≠ ∅ \). Let’s denote this relation as \(t ♯₀ t'\).

Definition 29 Conflict

def:net,def:immediate_conflict,def:preorder conflict Two elements \(x,y ∈ α ∪ β\) are in conflict if there exist two transtions \(t,t'\) that \(t≼ x\), \(t'≼ y\) and \(t ♯₀ t'\). We denote a conflict relation of \(x,y\) as \(x ♯ y\).

Definition 30 Backward conflict

def:immediate,def:net backward_conflict A place \(a\) has a backward conflict if it is produced by two distinct transitions, i.e., \(\exists t₁, t₂, (t₁ ≠ t₂) ∧ (a ∈ t₁• ) ∧ (p ∈ t₂•)\).

Definition 31 Acyclicity

def:causal,def:net acyclic A net is acyclic if its causal relation is irreflexive, i.e., there is no \(x ∈ α ∪ β\) such that \(x ≺_N x\).

Definition 32 Occurrence net

def:acyclic,def:postset_t,def:backward_conflict,def:MarkedNet,def:minimal,def:conflict,def:net,def:preset_t is_occurrence A marked net \((N,m_0)\) is an occurrence net if it satisfies the following statements:

  1. \(N\) is acyclic;

  2. there is no self-conflict, i.e., \(¬(t ♯ t)\) for all transition \(t\);

  3. there is no backward conflict;

  4. \(N\) is 1-safe, i.e., marking is a set;

  5. the initial marking is the set of initial places, i.e., \(m₀\) is minimal (Definition 6).

Definition 33 Marked occurrence net

def:MarkedNet,def:minimal,def:net,def:is_occurrence is_marked_occurrence A marked net \((N,m₀)\) is called marked ocurrence if \(N\) is occurrence, \(m₀\) has no duplicates and each place \(p ∈ m₀\) implies \(p ∈ \textsf{minimal }N\).

Definition 34 Concurrency

def:conflict,def:net,def:preorder concurrent Two different elements \(x,y∈ α ∪ β\) are concurrent in \(N\) if \(¬ (x≼ y)\), \(¬ (y ≼ x)\) and \(¬ (x ♯ y)\). We denote the concurrency between these elements as \(x \textsf{ co } y\).

Definition 35 Concurrent multiset

def:net,def:concurrent Concurrent A multiset \(m\) is concurrent in \(N\) if it no has duplicate and

\[ ∀ x, y ∈ α, (x ∈ m) ⇒ (y ∈ m) ⇒ x ≠ y ⇒ x\textsf{ co }y. \]

We’ll denote the concurrency of a multiset \(m\) by \(\textsf{Concurrent $m$}\).
