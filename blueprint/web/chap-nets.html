1 Nets

Definition 1 Net

Nets.Net A net \(N\) is a tuple \(N = (\alpha , \beta , \bullet {\_ }, \bullet {\_ })\), where \(\alpha \) is a nonempty set of places, \(\beta \) is the set of transitions, and \(•{\_ }, {\_ }•: \beta → ℕ ^{\alpha }\) assign source and target to each transition. We consider only nets in which every transition both consumes and produces, i.e., \(•t ≠ ∅ \) and \(t• ≠ ∅\) for all \(t∈ β\).

Definition 2 Preset for places.

def:net Nets.presetₚ A preset for places is a function that take a net \(N\), a place \(p\) and return the set \(\{ t \mid p ∈ t•\} \), where the postset function is defined in Definition 1.

Definition 3 Preset for transitions.

def:net Nets.presetₜ A preset for transitions is a function that take a net \(N\), a transition \(t\) and return the multiset \(•t\).

Definition 4 Postset for places.

Definition 5 Postset for transitions.

def:net Nets.postsetₜ A postset for transitions is a function that take a net \(N\), a transition \(t\) and return the multiset \(t•\).

The notation for preset of places or transition are written as \(\bullet _{ \{ \! \{ N \} \! \} }t\), but in this file we’ll use only the short notation \(•t\).

Definition 12 Firing sequence

def:is_enabled,def:net,def:is_firing Nets.firing_sequence firing_sequence N m ls m’ is the concatenation of sequences, where \(ls\) is the sequence of transitions, \(m\) is the initial marking (Definition 7) and \(m'\) the final marking of the sequence. We denote for \(s=ε\) for a empty sequence, in Lean this is an empty list, we denote for ’;’ the concatenation of lists. Therefore, a firing sequence is defined inductively as

  • Empty. \(m [[ε⟫ m\)

  • Inductive step. For a sequence \(t;s\) where \(t\) is a transition and \(s\) is a transition sequence, \(m[[t;s⟫ m'\) is a firing sequence if there is \(m''\) such that \(m[[t⟩m''\) is firing and \(m''[[s⟫ m'\) is a firing sequence.
